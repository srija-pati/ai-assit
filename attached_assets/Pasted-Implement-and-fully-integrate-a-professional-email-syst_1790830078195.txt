Implement and fully integrate a professional email system into the existing AI Legal application.

Do NOT create a separate email application. Modify the existing application while preserving all existing functionality.

## 1. EMAIL PROVIDER

Use **Resend** as the email delivery provider.

Use these backend environment variables:

```env
RESEND_API_KEY=your_resend_api_key
RESEND_FROM_EMAIL=website_verified_email@example.com
RESEND_FROM_NAME=AI Legal
```

Important:

* `RESEND_API_KEY` must remain server-side only.
* Never expose the API key in frontend JavaScript, HTML, API responses, logs, or browser storage.
* `RESEND_FROM_EMAIL` is the ONLY actual email address from which emails are sent.
* Users must NEVER be allowed to change the actual `From` email address.
* The website's verified Resend email must always remain the actual sender.

If the required Resend configuration is missing, return a clear configuration error instead of silently failing.

Every authenticated user must be able to send emails.

This includes:

# 4. HOW THE EMAIL MUST APPEAR

Suppose the user enters:

Sender Name:

`Pati Sravya`

Sender Email:

`sravya@gmail.com`

Recipient:

`client@example.com`

Subject:

`Legal Document`

Message:

`Please find the requested document attached.`

The actual email headers must be:

```text
From: AI Legal <website_verified_email@example.com>
To: client@example.com
Subject: Legal Document
```

The user's email MUST NOT replace the From address.

The email body should contain:

```text
AI LEGAL

Sender Details

Name: Pati Sravya
Email: sravya@gmail.com

Message

Please find the requested document attached.

Attachment

The requested legal document is attached to this email.
```

Make the email visually professional using a clean HTML email template.

Also provide a plain-text fallback version.

# 6. EMAIL API

Create or update:

```text
POST /api/send-email
```

The endpoint should accept:

```json
{
  "to": "recipient@example.com",
  "sender_name": "Pati Sravya",
  "sender_email": "sravya@gmail.com",
  "subject": "Legal Document",
  "message": "Please find the requested document attached.",
  "document_id": 123
}
```

The backend must:

1. Verify the user is authenticated.
2. Validate the recipient email.
3. Validate sender name.
4. Validate sender email.
5. Validate subject.
6. Validate message.
7. Verify Resend configuration.
8. Generate the HTML email.
9. Generate the plain-text email.
10. Attach the selected PDF if applicable.
11. Send the email using Resend.
12. Return a clear success response.
